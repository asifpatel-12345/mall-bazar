# 🛍️ Mall / Bazar - Modern E-Commerce Web Application

**Mall / Bazar** is a high-performance, dark-themed e-commerce web platform built with **Vanilla HTML5, CSS3, and JavaScript**. It features live product search, category filtering, a slide-in shopping cart drawer, persistent state using `LocalStorage`, and a fully responsive user interface.

---

## 🔥 Key Features

- **🎨 Cyberpunk Dark Aesthetic**: Built with modern CSS custom properties, glassmorphism, and responsive grid layouts.
- **⚡ Live Search & Category Filter**: Instant multi-category product filtering and real-time title searching without page reloads.
- **🛒 Dynamic Shopping Cart**: Slide-in drawer UI with real-time price calculation, item quantity management, and slide animations.
- **💾 LocalStorage Persistence**: Shopping cart items stay saved even if you refresh or reopen the page.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack & Tools

- **Frontend**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Icons & Fonts**: Font Awesome 6.4.0 & Google Fonts (Poppins)
- **Development Tool**: Visual Studio Code (VS Code) with Live Server
- **Version Control**: Git & GitHub
